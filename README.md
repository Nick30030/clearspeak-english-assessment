# ClearSpeak English placement assessment

A browser-based placement test with 30 progressive A1–C2 multiple-choice questions on grammar and vocabulary, an immediate screening estimate, and a written task for teacher review.

## Deployment

GitHub Pages deploys the site automatically from `main` through the workflow in `.github/workflows/pages.yml`.

## Important privacy limitation

This is a static preview. Student submissions are stored in each visitor's browser and do not reach a central teacher dashboard. The teacher password is embedded in client-side code and is not secure authentication. Do not collect sensitive student data or rely on that password for private access. Online student records require server-side authentication and a hosted database.
