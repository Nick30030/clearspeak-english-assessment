# ClearSpeak English placement assessment

A browser-based placement test with 40 progressive A1–C2 multiple-choice questions on grammar and vocabulary, an immediate screening estimate, and one written response for teacher review. Reading comprehension and speaking have been removed. The question set includes more nuanced B2–C2 language items to make upper-level placement more discriminating.

## Deployment

GitHub Pages deploys automatically from `main` through `.github/workflows/pages.yml`.

## Privacy limitation

This static preview stores student attempts in each visitor's browser. Submissions do not reach a central teacher dashboard. The teacher password is embedded in client-side code and is not secure authentication. Do not collect sensitive student data or rely on that password for private access. Online student records require server-side authentication and a hosted database.

The displayed CEFR level is a screening estimate from selected-response questions. A teacher should review writing before assigning a fuller level.
